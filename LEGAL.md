## 1. What OnionDesk is
OnionDesk is free, open-source desktop software by Sandip Bera ("the author"). It starts and controls the Tor client and an I2P router that you run on your own computer, shows their status, and includes a browser that reaches the web only through them. It is **not a VPN service**: there is no provider, no account and no server run by the author.
